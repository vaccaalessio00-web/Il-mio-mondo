# Immagine per la Pagina 8 del Diario

Inserisci qui la tua immagine personalizzata da mostrare nella **Pagina 8 del Diario** al posto di Puzzola.

- Formati supportati: `.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`
- Nome file: puoi usare qualsiasi nome (es. `pagina8.png`, `foto.jpeg`, `mascotte.png`, ecc.)

L'applicazione rileva e carica automaticamente l'immagine posizionata in questa cartella!
