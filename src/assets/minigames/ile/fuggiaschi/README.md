# 🦝 Immagini dei Fuggiaschi (Ile in azione)

Inserisci qui le immagini dei fuggiaschi / bersagli da catturare nel gioco!
Puoi inserire più immagini (es. `fuggiasco1.png`, `ladro.png`, `furbetto.jpg`, ecc.).

Il gioco le caricherà e le mostrerà a random quando spuntano sullo schermo.
I formati consigliati sono `.png` o `.webp` (meglio se con sfondo trasparente) o `.jpg`/`.jpeg`.
