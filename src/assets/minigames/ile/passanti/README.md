# 🚶‍♀️ Immagini dei Passanti / Civili (Ile in azione)

Inserisci qui le immagini dei passanti / civili pacifici da proteggere!
Puoi inserire più immagini (es. `passante1.png`, `cane.png`, `postino.jpg`, `civile.png`, ecc.).

Il gioco le caricherà e le mostrerà a random quando attraversano la strada o passeggiano.
Se toccati per sbaglio, il gioco bloccherà dolcemente la strada per 1 secondo per respirare!
I formati consigliati sono `.png` o `.webp` (meglio se con sfondo trasparente) o `.jpg`/`.jpeg`.
