# 🎮 Cartelle Immagini Minigiochi (`src/assets/minigames/`)

In queste cartelle puoi inserire le immagini dedicate ai minigiochi rilassanti:

---

## 📁 Struttura Cartelle e Nomi File Consigliati

### 1. 🍳 In Cucina con Mimmi
- **Cartella:** `src/assets/minigames/mimmi/` (o direttamente in `src/assets/minigames/`)
- **Nome file consigliato:** `mimmi.jpeg` (o `mimmi.jpg`, `mimmi.png`)
- **Dove apparirà:** Come avatar/volto di Mimmi durante la preparazione delle ricette rilassanti.

### 2. 🪵 La Bottega di Papà
- **Cartella:** `src/assets/minigames/papa/` (o direttamente in `src/assets/minigames/`)
- **Nome file consigliato:** `papa.jpeg` (o `papa.jpg`, `papa.png`)
- **Dove apparirà:** Come avatar/volto di Papà mentre levighi e crei i tuoi oggetti in legno.

### 3. 🐾 Ninni al Traguardo (Passo dopo Passo con Ninni)
- **Cartella:** `src/assets/minigames/ninni/` (o direttamente in `src/assets/minigames/`)
- **Nome file consigliato:** `ninni_traguardo.jpeg` (o `ninni.jpeg`, `ninni_traguardo.png`)
- **Dove apparirà:** Nel riquadro di celebrazione quando Ninni raccoglie tutti i biscottini e arriva alla sua cuccia!

### 4. 💋 Ora, Ora !
- **Cartella:** `src/assets/minigames/oraora/`
- **File:** `background.png`, `models_idle.png`, `models_kissing.png`, `friends_idle.png`, `friends_signal.png`, `boss_hidden.png`, `boss_warning.png`, `boss_watching.png`, `boss_caught.png`
- **Dove apparirà:** Nel minigioco Ora Ora, puoi personalizzare lo sfondo, le modelle, le amiche e il capo inserendo qui le tue immagini (PNG/JPG/WEBP).

---

## ⚡ Rilevamento Automatico
Il codice è già predisposto per **rilevare automaticamente** i file appena li salvi in queste cartelle. Non c'è bisogno di modificare codice manuale!
