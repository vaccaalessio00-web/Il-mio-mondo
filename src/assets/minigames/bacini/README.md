# Immagini per il gioco "Bacini a volontà"

In questa cartella puoi inserire le immagini per il gioco:

1. **Immagini di Sfondo** (es. `sfondo.jpg`, `sfondo (1).jpg`, `sfondo (2).jpg`, `sfondo (12).jpg`, ecc.):
   - Vengono usate a tutto schermo come sfondo del gioco.
   - Variano casualmente e automaticamente durante la partita (ogni 5-7 bacini) e all'avvio di una nuova partita.

2. **Immagini Centro** (es. `centro (1).jpg`, `centro (2).jpg`, `centro.jpg`, ecc.):
   - Il personaggio al centro dello schermo da cliccare per mandare bacini.
   - Vengono automaticamente **scontornate** per rimuovere lo sfondo e integrarsi senza cornici bianche.

3. **Immagini Fine** (es. `Fine.png.jpeg`, `Fine 2.png.jpeg`, `Fine 3.png.jpeg`, `Fine 4.png.jpeg`):
   - Mostrate nel pop-up finale quando si raggiunge l'obiettivo dei bacini.

I file vengono rilevati automaticamente dall'applicazione!
