# 🫧 Cartella Immagini Personalizzate: Magi, cosa fai?!

In questa cartella puoi inserire le immagini per personalizzare il gioco:

1. **`sfondo/`**:
   - Inserisci qui l'immagine di sfondo dove c'è **già Magi all'interno della vasca da bagno** (es. `sfondo.png`, `sfondo.jpg`, `vasca.png`, `magi_vasca.png`).
   - Quando inserita, sostituirà o farà da base allo scenario di Magi nella vasca.

2. **`tatuaggi/`**:
   - Inserisci qui i vari tatuaggi/disegni che devono comparire sul corpo di Magi (es. `tatuaggio1.png`, `tatuaggio2.png`, `cuore.png`, `farfalla.png`, ecc.).
   - Supporta immagini trasparenti PNG per posizionarsi perfettamente sulla pelle di Magi!

3. **`piange/`**:
   - Inserisci qui l'immagine che deve apparire quando Magi piange (es. `piange.png`, `magi_piange.png`, `crying.png`).
   - Apparirà con un'animazione speciale al momento del pianto!
