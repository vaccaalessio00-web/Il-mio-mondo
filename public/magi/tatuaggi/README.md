# 🎨 Cartella Tatuaggi: Magi, cosa fai?!

Inserisci qui tutte le immagini dei tatuaggi che vuoi far comparire sulla pelle della ragazza!

- **Formati supportati**: PNG (consigliato con sfondo trasparente), JPG, JPEG, WEBP, SVG.
- **Nomi file**: puoi nominarli come preferisci (es. `tatuaggio1.png`, `cuore.png`, `farfalla.png`, `drago.png`, `fiore.png`, ecc.).
- Se un'immagine ha uno sfondo bianco, il gioco rimuoverà automaticamente lo sfondo per renderlo trasparente sulla pelle.
- Puoi anche caricare o aggiungere tatuaggi direttamente dall'interfaccia di gioco tramite il pulsante "Aggiungi Tatuaggio".
